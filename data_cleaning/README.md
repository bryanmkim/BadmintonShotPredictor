# Data Cleaning Notes

The scripts in this folder are helper utilities for preparing and filtering the badminton dataset.

They are not required to run the main training workflow in the project root.

## Files

- data_filter.py — creates a simplified CSV from the raw dataset
- data.py — defines the RallyDataset class used by the training script

If you are only trying to train the model, you can ignore this folder unless you need to regenerate or modify the input data.
